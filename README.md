## Practice Projects

12 projects from beginner to advanced. Complete each independently before moving on.

### Level 1 — Fundamentals
| # | Project | Key Concepts |
|---|---|---|
| 1 | CLI Calculator | Variables, operators, functions, conditions |
| 2 | Number Guessing Game | Loops, conditions, random, input validation |
| 3 | Expense Tracker | Lists, dictionaries, functions, aggregation |

### Level 2 — Intermediate
| # | Project | Key Concepts |
|---|---|---|
| 4 | Contact Management System | CRUD, JSON, file handling, validation |
| 5 | File Organizer | `pathlib`, `os`, `shutil`, automation |
| 6 | CLI Task Manager | OOP, dataclasses, enums, sorting, filtering |

### Level 3 — Advanced Python
| # | Project | Key Concepts |
|---|---|---|
| 7 | Log Analyzer | Regex, generators, `Counter`, data processing |
| 8 | REST API Client | HTTP, JSON, authentication, retries, exceptions |
| 9 | Web Scraper | HTML parsing, HTTP, persistence, rate limiting |

### Level 4 — Backend Engineering
| # | Project | Key Concepts |
|---|---|---|

| 11 | Concurrent Data Processor | Asyncio, threading, concurrency, performance |
